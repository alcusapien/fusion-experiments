# Open Source Software at Photon

We use free and open source software across Photon SDKs, in the Photon Server and Photon Cloud backend.

This page lists the open source and other third-party software used by Photon products and their respective licenses.

### Photon Server and Plugins SDKs

#### v4

See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Photon_Server_v4.pdf">Photon Server and Plugins SDKs open source licenses</a>.

#### v5

See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Photon_Server_v5.pdf">Photon Server and Plugins SDKs open source licenses</a>.

### Photon Native Client SDKs

See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Native_Client_SDKs.pdf">Photon Native Client SDKs open source licenses</a>.

### Photon .NET Client SDKs

See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-.NET_Client_SDKs.pdf">Photon .NET Client SDKs open source licenses</a>.

### Photon Unity Networking (PUN)

PUN (and PUN+) builds on top of the Photon .NET Client and all of the open source software (OSS) used by it.
See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-PUN.pdf">Photon Unity Networking (PUN) "exclusive" open source licenses</a>.

### Photon Voice

Photon Voice package includes Photon Unity Networking (PUN) and all of the open source software (OSS) used by it.
See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Photon_Voice.pdf">Photon Voice "exclusive" open source licenses</a>.

### Photon Quantum

Photon Quantum v1 package includes Photon Unity Networking (PUN) Classic and all of the open source software (OSS) used by it.
Photon Quantum v2 and v3 packages includes Photon Realtime Unity SDK (Photon .NET Client SDK) and all the open source software (OSS) used by it.
See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Photon_Quantum.pdf">Photon Quantum "exclusive" open source licenses</a>.

### Photon Fusion

See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Photon_Fusion.pdf">Photon Fusion open source licenses</a>.

### Photon Bolt

Photon Bolt package includes Photon Realtime Unity SDK (Photon .NET Client SDK) and all the open source software (OSS) used by it.
See the list of <a href="https://dev-doc.photonengine.com/docs/content/OSS-Photon_Bolt.pdf">Photon Bolt "exclusive" open source licenses</a>.
