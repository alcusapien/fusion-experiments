# Fusion Experiments

Experiments with the Photon Fusion 3 port for Godot.

## Setup

1. Install [Godot 4.7.2](https://godotengine.org/download).
2. Download the [Photon Fusion SDK for Godot](https://doc.photonengine.com/fusion-godot/v3-shared-authority/getting-started/sdk-download)
   and extract it into `addons/fusion/` in the project root. (This directory is
   git-ignored and must be added manually.)
3. Open `project.godot` in Godot and run the project.
